# Анализ датасета «Туризм в Индии»

Pet-проект по исследовательскому анализу данных (EDA) на основе датасета с Kaggle о туристических достопримечательностях Индии.

## Задача
- Подготовить сырые данные к анализу
- Выполнить исследовательский анализ данных (EDA)
- Визуализировать результаты с помощью библиотек Python

## Инструменты
- **Python:** pandas, numpy
- **Визуализация:** matplotlib, seaborn, plotly, folium
- **Среда:** Jupyter Notebook

## Что было сделано
1. Загрузка и очистка данных: убраны пробелы в названиях столбцов, обработаны пропуски и дубликаты, определены типы данных
2. Feature engineering: теги разбиты на список, определён город по названию, подсчитаны топ-15 тегов и топ-10 городов
3. Визуализация: топ-15 тегов, распределение тегов, география объектов, тепловая карта, интерактивная карта (Plotly, Folium)

## Ключевые выводы
- **2/3 всех достопримечательностей** сосредоточены в двух регионах:
  - Керала — 193 объекта
  - Район Дели — 139 объектов
- Датасет сфокусирован на двух ключевых туристических регионах Индии

## Результат
Интерактивная карта сохранена в файл `tourist_map.html` и может быть встроена в веб-приложение для туристов.
